## Major Milestones

### Milestone A — Specification Ready
Phase 0 selesai.

### Milestone B — Foundation Ready
Phase 1–2 selesai.

### Milestone C — Anime Tracker MVP
Phase 3–6 selesai.

User sudah dapat register, menemukan anime, membuka detail, menambahkan anime ke list, mengubah status, memperbarui episode, memberi score, menyelesaikan anime, dan melihat anime list.

### Milestone D — Complete Anime Experience
Phase 7–8 selesai.

Profile, statistics, favorites, seasonal anime, dan airing schedule sudah terintegrasi.

### Milestone E — Identity & Gratification
Phase 9 selesai.

Achievement engine, permanent milestones, progress, unlockable titles, dan three-slot profile showcase tersedia.

### Milestone F — Social Platform V1
Phase 10 selesai.

Social, reviews, moderation, quality hardening, dan production readiness selesai.

## Development Rule

Detail task hanya dibuat untuk:
- phase yang sedang dikerjakan; dan
- phase berikutnya.

Roadmap jangka panjang tetap high-level agar project dapat beradaptasi berdasarkan hasil implementasi nyata.


## Post-Phase-12 Governance Gates
- Public image/background sourcing and rights must be reviewed and explicitly authorized.
- Canonical synopsis approval/publication is deferred; current review supports requests for changes and rejection only.
- Manga/Music catalog publication requires curated provenance/eligibility evidence.
- External rankings and production deployment need independent approval/verification.
