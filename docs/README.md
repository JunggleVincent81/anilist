# Anime Platform Documentation

Dokumentasi ini menjadi sumber kebenaran utama untuk keputusan produk, arsitektur, implementasi, dan laporan pengerjaan proyek.

## Aturan dokumentasi
1. Setiap phase memiliki tujuan, batas scope, dan acceptance criteria.
2. Laporan fase disimpan di `99-reports/` dengan nama `PHASE-XX-COMPLETION-REPORT.md`.
3. Perubahan keputusan yang di-lock harus dicatat, termasuk perubahan pada phase berikutnya.
4. Commit/push mengikuti verifikasi dan approval pengguna.
5. Technical scope complete **bukan** otorisasi untuk publikasi konten atau deployment production.
