# Anime Platform

Anime-only tracking, discovery, statistics, achievement, and social platform.

Phase 1 establishes the project foundation only. Product features and domain modules are intentionally deferred to later phases.

## Workspace

- `apps/web` — Next.js frontend.
- `apps/api` — NestJS GraphQL API.
- `packages/shared` — shared TypeScript foundation package.
- `docs` — product and phase documentation.

## Commands

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

See `docs/01-foundation/LOCAL-DEVELOPMENT.md` for local setup and database instructions.
